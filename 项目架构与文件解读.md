# 项目架构与文件功能解读

**Web 开发课程教学项目** —— 一个全栈的课程目录应用。采用 **npm workspaces 单体仓库**（monorepo）结构管理前端和后端。

---

## 🏗️ 整体架构图

```
┌─────────────────────────────────────────────────────────┐
│                     用户浏览器                           │
└─────────────┬───────────────────────────────────────────┘
              │  :3000
              ▼
┌─────────────────────────┐    API 代理     ┌──────────────────┐
│   Frontend (Next.js)    │  /api/* ──────▶ │  Backend (Midway) │
│   端口: 3000             │  next.config    │  端口: 7001       │
└─────────────────────────┘    rewrites     └──────┬───────────┘
                                                   │
                                              ┌────▼────┐
                                              │ SQLite  │
                                              │ (内置)   │
                                              └─────────┘
```

请求流程：

1. 浏览器访问 `localhost:3000`
2. Next.js 渲染 React 页面
3. 客户端组件通过 `fetch('/api/courses')` 调用 API
4. Next.js 的 `rewrites` 将 `/api/*` 代理到后端 `localhost:7001`
5. Midway.js 处理请求、读写 SQLite
6. 返回 JSON 数据

## 🖥️ Frontend（`frontend/`）— Next.js 16 + React 19 + Tailwind CSS 4

### 配置文件

| 文件                 | 功能                                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `package.json`       | 声明 Next.js 16、React 19、Tailwind CSS 4、ESLint 9 等依赖                                                                             |
| `next.config.ts`     | Next.js 配置：`output: "standalone"`（Docker 优化输出），**核心功能**：`/api/:path*` 请求全部 rewrite 到后端 `${BACKEND_INTERNAL_URL}` |
| `tsconfig.json`      | TypeScript 严格模式，路径别名 `@/* → ./src/*`                                                                                          |
| `postcss.config.mjs` | Tailwind CSS v4 的 PostCSS 插件配置                                                                                                    |
| `eslint.config.mjs`  | ESLint 9 规范，继承 Next.js 的 core-web-vitals + TypeScript 规则                                                                       |
| `next-env.d.ts`      | Next.js 自动生成的 TypeScript 类型声明文件                                                                                             |

### 源码 `frontend/src/`

| 文件                              | 功能                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `app/layout.tsx`                  | **根布局**：设置 HTML 语言为 `zh-CN`，页面元数据（title: "Web 开发课程"），引入全局样式                                                                                                                                                                                                                                                                                        |
| `app/page.tsx`                    | **首页**（服务端组件）：渲染页面标题和 `CourseDashboard` 客户端组件                                                                                                                                                                                                                                                                                                            |
| `app/globals.css`                 | **全局样式**：Tailwind v4 的 `@import "tailwindcss"` 和浅色主题 CSS 自定义属性                                                                                                                                                                                                                                                                                                 |
| `components/course-dashboard.tsx` | **课程仪表盘**（客户端组件 `"use client"`）：使用 `useEffect` + `AbortController` 调用 `/api/health` 和 `/api/courses`，处理四种状态——**加载中**（3 个骨架屏卡片 + `animate-pulse`）、**错误**（红色错误横幅）、**空列表**（应显示空状态但已知有 bug）、**成功**（响应式课程卡片网格 1/2/3 列）；顶部有 API 连接状态指示器（绿色"已连接" / 红色"连接失败" / 琥珀色"正在连接"） |

## ⚙️ Backend（`backend/`）— Midway.js 4 + Koa + SQLite

### 配置文件

| 文件            | 功能                                                                 |
| --------------- | -------------------------------------------------------------------- |
| `bootstrap.js`  | **生产入口**：创建 Midway Bootstrap 实例并调用 `.run()` 启动服务     |
| `package.json`  | 声明 Midway.js（core / koa / bootstrap / logger）、TypeScript 等依赖 |
| `tsconfig.json` | TypeScript 严格模式，ES2022，装饰器元数据启用（Midway 依赖注入所需） |

### 源码 `backend/src/`

| 文件                           | 功能                                                                                                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `configuration.ts`             | **应用配置类**（`@Configuration` 装饰器）：注册 Koa 框架、导入配置模块、扫描控制器和服务                                                                                                                     |
| `config/config.default.ts`     | **默认配置**：Koa 端口 7001、SQLite 数据库路径、密钥等                                                                                                                                                       |
| `controller/api.controller.ts` | **API 控制器**（`@Controller("/api")`）：3 个端点——`GET /api/health`（健康检查，返回服务名和时间戳）、`GET /api/courses`（课程列表，按 id 排序）、`POST /api/courses`（创建课程，含输入校验，返回 400 错误） |
| `service/course.service.ts`    | **课程服务**（`@Provide()` 装饰器）：`@Init` 时建库目录 + 建表 + 插入 3 条种子数据；`list()` 查询全部课程；`create()` 插入新课；`@Destroy` 时关闭数据库连接                                                  |
| `utils/course-input.ts`        | **输入校验工具**：`parseCourseInput()` 验证对象非空非数组，title（2-80 字符）、description（2-500 字符）                                                                                                     |
| `interface.ts`                 | **TypeScript 接口定义**：`Course`（id, title, description, credits, createdAt）、`CreateCourseInput` 类型                                                                                                    |

### API 端点总结

| 方法 | 路径           | 处理函数             | 说明                                                                              |
| ---- | -------------- | -------------------- | --------------------------------------------------------------------------------- |
| GET  | `/api/health`  | `health()`           | 返回 `{ status: "ok", service, timestamp }`                                       |
| GET  | `/api/courses` | `listCourses()`      | 返回 `{ data: Course[] }` 按 id 排序                                              |
| POST | `/api/courses` | `createCourse(body)` | 校验输入 → 创建课程 → 返回 `{ data: Course }`；输入无效时抛 `400 BadRequestError` |

| 文件                         | 功能                                                 |

| `test/course-input.test.mts` | 输入校验测试：验证合法修剪后的输入、验证空输入被拒绝 |

## 📌 已知问题与改进方向（来自架构审查）

### P0 — 契约可信度

- OpenAPI 声明 `additionalProperties: false`，但运行时静默忽略多余字段
- 缺少 OpenAPI lint 的 CI 检查
- `POST /api/courses` 应返回 `201 Created` 而非 `200 OK`
- 缺少结构化的错误响应 JSON schema
- 缺少契约测试（contract testing）

### P1 — 课程边界

- 前端将空数组 `[]` 误判为加载中（未区分空列表和加载状态）
- 内联的 API 类型应集中管理，理想情况下从 OpenAPI 生成
- 可优先使用服务端组件替代客户端 `useEffect` 数据获取
- 随着复杂度增长，需要独立的 Repository / DTO / Migration 层
- 生产环境 Koa 密钥硬编码

### P2 — 交付工程

- 缺少 `.dockerignore` 文件
- 跨领域关注点（如中间件）尚未提取
